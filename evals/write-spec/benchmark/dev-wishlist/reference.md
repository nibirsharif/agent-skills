Set: dev. Domain: UI. Form: user story.

Open decisions:
- R1: Which system adds products to the wishlist and displays the wishlist page.
- R2: How a shopper removes an item: which control, on which page.
- R3: What happens when a shopper clicks the heart button of a product that is already in the wishlist.
- R4: What happens when a shopper who is not signed in clicks the heart button, or whether a wishlist needs an account at all.
- R5: What the wishlist page shows for a saved product that is no longer sold.

Not given: a system name, a sign-in rule, a limit on the number of items.
