Requirements for the export service: when an admin clicks "Export CSV" on the Reports page, the export service emails the report as a CSV file to that admin's email address within 5 minutes of the click. If the report has more than 100,000 rows, the export service rejects the export and displays "Report too large to export". Where the audit module is installed, the export service logs every export with the admin's user ID and the export time in UTC.
