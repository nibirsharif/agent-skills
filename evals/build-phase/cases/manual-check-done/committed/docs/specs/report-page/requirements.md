# Requirements: Report Page

**Version:** 1.0
**Date:** 2026-11-10
**Status:** Draft

## 1. Functional Requirements

FR-001: When a caller passes text to `render_report`, the textstats library shall return an HTML page that contains the text's word count.

FR-002: When a user clicks the Copy button on the report page, the report page shall copy the word count to the clipboard.
